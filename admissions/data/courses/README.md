# Каталог курсов

ИИ-помощник советует курсы **только из этого каталога**, по id. Так он не придумает
несуществующий курс или неверную ссылку. Если подходящего курса в каталоге нет,
помощник описывает курс по типу («онлайн-курс основ Python»), без названий и ссылок.

Загрузка: `python manage.py load_courses`. Повторная загрузка обновляет курсы по `code`,
курсы, которых нет в файле, удаляются.

## Формат `courses.json`

```json
{
  "courses": [
    {
      "code": "hse-olymp-informatics",
      "kind": "course",
      "title": "Название курса, как на сайте",
      "provider": "Кто проводит (вуз, школа, платформа)",
      "url": "https://... страница курса у того, кто его проводит",
      "description": "1–2 предложения: чему учит, для кого",
      "directions": ["09", "01.03.02"],
      "grades": [10, 11],
      "subjects": ["informatics", "math"],
      "is_free": true,
      "verified": false
    }
  ]
}
```

- `kind`: вид. `course` — подготовка к ОГЭ и ЕГЭ, `school` — профильная школа или кружок,
  `online_school` — онлайн-школа, `event` — лекции и встречи, `excursion` — экскурсия,
  `profproba` — профпроба.
- `grades`: для каких классов (9, 10, 11). Пусто: класс не важен. Помощнику передаются
  только курсы для класса школьника.
- `subjects`: школьные предметы (коды как в каталоге профессий).
- Курс показывается на странице профессии: если у курса есть `directions`, то по ним,
  иначе по `subjects` (по одному русскому языку не привязываем).
- `directions`: к каким направлениям подходит курс. `09` — вся группа (информатика),
  `09.03.04` — одно направление. Помощнику передаются курсы, подходящие к программам
  из подбора школьника (не больше 15).
- `url`: страница курса на сайте того, кто его проводит. Агрегаторы курсов не используем.
  Сейчас в каталоге: вузы Москвы (ВШЭ, МГТУ им. Баумана, РАНХиГС), онлайн-школы
  (Сириус.Курсы, ЗФТШ МФТИ), Яндекс Лицей и экскурсии «Открой#Моспром». Собрано 28 октября 2026 года
  со страниц на 2026/2027 учебный год. Онлайн-школы — не конкуренты, их берём с их собственных сайтов.
- Не вошли: Сеченовский (на сайте нет актуальных программ, вопрос 35), «Субботы московского
  школьника» (у сайта записи school.moscow истёк сертификат, новости на mos.ru старые).
- `verified`: `true` ставит человек, открывший ссылку и проверивший, что курс существует
  и описание верное. Непроверенные курсы попадают к помощнику, только пока
  `SHOW_UNVERIFIED_DATA=True`.
- Неизвестное значение не выдумываем: поле пропускаем.
