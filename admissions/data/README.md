# Данные о вузах

Один файл = один вуз, имя файла совпадает с `code` (например, `hse.json`).

Данные берутся **только с официальных сайтов вузов**, сайты-агрегаторы не используем.
Файлы собирает скрипт `tools/collect_official.py`, у каждой цифры ссылка на страницу
или документ вуза. Источники по вузам:

| Вуз | Проходные баллы | Места | Предметы |
|---|---|---|---|
| ВШЭ | ba.hse.ru/result2021…2025 | ba.hse.ru/kolmest… | ba.hse.ru/minkrit |
| МГТУ им. Баумана | страница направления на bmstu.ru (2023–2026) | там же | там же |
| РАНХиГС | ranepa.ru/bakalavriat/prokhodnoy-ball (2023–2025) | PDF «Количество мест» | PDF «Перечень вступительных испытаний» |
| Сеченовский | каталог priem.sechenov.ru (2025) | там же | там же |

МФТИ пока нет: его сайт приёмной комиссии не отдаёт данные автоматическим запросам.

Сбор и загрузка в базу:

```
python tools/collect_official.py            # все вузы (нужен pip install -r requirements-tools.txt)
python manage.py load_universities          # все файлы
python manage.py load_universities hse      # только этот
```

Повторная загрузка обновляет данные. Программы, которых нет в файле, удаляются.
Если в файле ошибка, база не меняется.

## Формат

```json
{
  "code": "hse",
  "name": "Национальный исследовательский университет «Высшая школа экономики»",
  "short_name": "ВШЭ",
  "website": "https://www.hse.ru",
  "has_dormitory": true,
  "source_url": "https://ba.hse.ru/...",
  "verified": false,
  "programs": [
    {
      "faculty": "Факультет компьютерных наук",
      "name": "Программная инженерия",
      "direction_code": "09.03.04",
      "study_form": "full_time",
      "tuition_per_year": 750000,
      "source_url": "https://...",
      "verified": false,
      "exams": [
        {"subject": "math", "min_score": 75},
        {"subject": "russian", "min_score": 60},
        {"one_of": [
          {"subject": "informatics", "min_score": 70},
          {"subject": "physics", "min_score": 70}
        ]}
      ],
      "stats": [
        {"year": 2025, "passing_score_budget": 285, "budget_places": 150,
         "passing_score_paid": 240, "paid_places": 60, "source_url": "https://..."}
      ]
    }
  ]
}
```

- `study_form`: `full_time` (очная), `part_time` (очно-заочная), `distance` (заочная).
- Предметы: `math`, `russian`, `informatics`, `physics`, `chemistry`, `biology`,
  `social`, `history`, `literature`, `english`.
- `one_of`: один предмет на выбор. Засчитывается тот, что выгоднее школьнику.
- `passing_score_budget`: проходной балл на бюджет по общему конкурсу,
  как его публикует вуз: это сумма ЕГЭ **вместе** с индивидуальными достижениями (до +10),
  поэтому оценка шансов по одним баллам ЕГЭ получается чуть осторожнее. Если все бюджетные
  места заняли олимпиадники и квотники («-*», «*»), балла нет. Год, где балл больше
  100 × число предметов + 10, не берём: тогда экзаменов было больше (у ВШЭ до 2023 года — 4).
- `budget_places`: все бюджетные места вместе с квотами (особой, отдельной, целевой).
- `passing_score_paid`, `paid_places`: проходной балл и число мест на платное (для граждан РФ).
  ВШЭ публикует проходной на платное с 2025 года. Если балла на платное нет, шансы на платное
  не оцениваем, показываем только стоимость.
- `tuition_per_year`: стоимость платного обучения в год, руб.
- `min_score`: минимальный балл, установленный вузом (не минимальный порог Рособрнадзора).
- `source_url` у программы и у каждого года: откуда взяты цифры. Если не указан
  у программы, берётся ссылка вуза.
- `verified`: `true` ставит только человек, сверивший цифры с источником.
- Неизвестное значение не выдумываем: поле пропускаем.
