# Проект: профориентация школьников 11 класса (прототип)

## Цель
Рабочий прототип для демонстрации на конференции (январь). Помогает школьнику 11 класса и его родителю понять, какие направления и вузы Москвы подходят, и составить стратегию поступления.

## Принципы
- Код считает шансы (категории: амбициозно / реалистично / страховка), LLM только объясняет и строит стратегию по готовым данным из базы.
- Данные только обезличенные: никаких ФИО, контактов, названий школ. Участники имеют коды.
- У каждого факта о вузе есть source_url, updated_at, verified. Пока данные никто не сверяет, непроверенные записи показываются с пометкой «не проверено» (настройка SHOW_UNVERIFIED_DATA в .env). Для реального запуска SHOW_UNVERIFIED_DATA=False: в отчёт идут только проверенные. Цифры не выдумываем: неизвестное поле оставляем пустым.
- Тесты и правила хранятся как данные, а не в коде.
- LLM вызывается через один модуль-обёртку (сейчас Qwen), чтобы менять модель в одном месте.
- Ответ LLM в JSON, проверка схемой (Pydantic), программы сверяются с id из базы.

## Стек
Python 3.12, Django, SQLite на время прототипа, запуск локально.

## Правила работы
- Владелец проекта изучает Python: объяснять каждое решение простыми словами.
- Небольшие шаги, тесты для движка расчёта шансов.
- Секреты только в .env, в Git их не добавлять.
