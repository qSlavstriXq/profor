# Оформление сайта

| Что | Где |
|---|---|
| Цвета, шрифты, размеры | `css/main.css`, блок `:root` в начале файла |
| Логотип в шапке | `img/logo.svg` (заменить файл) |
| Иконка во вкладке браузера | `img/favicon.svg` |
| Фото для баннера на главной | `img/hero.jpg`, затем раскомментировать строку в `pages/templates/pages/home.html` |
| Другие фото | `img/photos/` |
| Логотипы партнёров в подвале | `img/partners/`, пример в `templates/includes/footer.html` |
| Скрипты | `js/main.js` |

Общий каркас страниц: `templates/base.html`, шапка и подвал: `templates/includes/`.

В шаблоне картинка подключается так:

```django
{% load static %}
<img src="{% static 'img/photos/students.jpg' %}" alt="Описание фото">
```

Сюда кладутся файлы оформления, которые хранятся в Git.
Фото, которые загружают через админку (например, логотипы вузов),
попадают в папку `media/` и в Git не добавляются.
