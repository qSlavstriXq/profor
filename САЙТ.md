# Адрес сайта

Сайт работает на этом компьютере по адресу **http://127.0.0.1:8000/**
(быстрый вход: двойной щелчок по файлу `Сайт.url` в папке проекта).

Перед этим сайт нужно запустить. В терминале PyCharm, в папке проекта:

```
python manage.py runserver
```

Остановить: Ctrl+C в том же терминале.

## Страницы

| Страница | Адрес                                          |
|---|------------------------------------------------|
| Главная | http://127.0.0.1:8000/                         |
| Профтесты | http://127.0.0.1:8000/tests/                   |
| Подбор программ | http://127.0.0.1:8000/programs/                |
| Профессии | http://127.0.0.1:8000/professions/ |
| Профессия (пример) | http://127.0.0.1:8000/professions/programmist/ |
| Мои результаты | http://127.0.0.1:8000/tests/my/                |
| Моя стратегия | http://127.0.0.1:8000/tests/my/strategy/       |
| О проекте | http://127.0.0.1:8000/about/                   |
| Админка (вузы, тесты, результаты) | http://127.0.0.1:8000/admin/                   |
| Профессии в админке | http://127.0.0.1:8000/admin/careers/profession/ |
| Образец личностного теста* | http://127.0.0.1:8000/tests/personality-example/ |
| Образец теста по математике* | http://127.0.0.1:8000/tests/knowledge-math-example/ |

\* Образцы формата видны, только если загружены командой `python manage.py load_tests --examples`.
Перед конференцией их нужно скрыть: `python manage.py load_tests --hide-examples`.

Вход в админку — логин суперпользователя. Если его ещё нет:
`python manage.py createsuperuser`.

127.0.0.1 — это «этот компьютер»: с телефона или другого компьютера такой адрес не откроется.
Для показа на конференции с других устройств нужен сервер (см. `QUESTIONS.md`, вопрос 16).

## Показать сайт другому человеку (временная ссылка)

Сайт продолжает работать на этом компьютере, а человек открывает его по ссылке в интернете.
Ссылка работает, пока компьютер включён и запущены обе команды ниже.

1. В `.env` должно быть:
   ```
   DJANGO_DEBUG=False
   DJANGO_ALLOWED_HOSTS=127.0.0.1,localhost,.lhr.life
   DJANGO_CSRF_TRUSTED_ORIGINS=https://*.lhr.life
   ```
   `DJANGO_DEBUG=False` обязательно: иначе при ошибке посторонние увидят код и настройки.
2. Первый терминал — запустить сайт (`--insecure` нужен, чтобы при выключенной отладке
   показывались стили и картинки):
   ```
   python manage.py runserver --insecure
   ```
3. Второй терминал — открыть туннель через сервис localhost.run (без регистрации):
   ```
   ssh -R 80:127.0.0.1:8000 nokey@localhost.run
   ```
   В ответе будет адрес вида `https://xxxxxxxx.lhr.life` — его и отправляйте.
   Адрес меняется при каждом запуске и иногда сам по себе, тогда пришлите новый.
4. Остановить: Ctrl+C в обоих терминалах.

Cloudflare Tunnel у нас не работает: провайдер не пропускает соединения к его серверам.
Админка (`/admin/`) тоже доступна по ссылке, поэтому пароль администратора должен быть надёжным.
Для обычной работы над сайтом верните `DJANGO_DEBUG=True`: тогда ошибки видны подробно.
